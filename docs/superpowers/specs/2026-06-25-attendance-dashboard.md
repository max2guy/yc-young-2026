# 출결현황 읽기 전용 대시보드 설계

## 목표
- 회의자료 사이트 안에 `출결현황` 메뉴를 추가한다.
- `ministry-report-v2`에서 관리 중인 출결 데이터를 그대로 읽어 온다.
- 이 사이트에서는 `중고등부(middleHigh)` 데이터만 읽기 전용으로 보여 준다.
- 회의 때 바로 확인하기 좋게 `상단 요약 + 주간 목록 + 월별 요약`을 한 화면에 정리한다.

## 사용자 기준
- 회의자료 사이트 안에서 별도 로그인 흐름 없이 출결 현황으로 이동할 수 있어야 한다.
- 최근 주 출석, 이번 달 흐름, 월별 변화가 한 번에 보여야 한다.
- 실제 수정 위치는 그대로 `ministry-report-v2`이므로, 이 화면은 보기와 확인에 집중해야 한다.

## 선택한 방향
- 출결 화면은 `index.html` 안에 억지로 넣지 않고 `attendance.html` 별도 페이지로 만든다.
- 회의자료 사이트 사이드바에 `출결현황` 네비게이션 항목을 추가한다.
- 데이터는 `ministry-report-v2`의 Firebase Firestore `reports` 컬렉션을 직접 읽는다.
- 읽은 보고서 중 `departments.middleHigh`만 추출해 통계를 계산한다.

## 데이터 기준
- 데이터 소스: `ministry-report-v2/src/storage/firestoreReportStore.ts`
  - 컬렉션: `reports`
- Firebase 연결 기준: `ministry-report-v2/src/lib/firebase.ts`
  - Firestore를 사용한다.
- 출결 대상 필드:
  - `reportDate`
  - `departments.middleHigh.attendance`
  - `departments.middleHigh.members`
  - `departments.middleHigh.name`
- 총원 계산:
  - `members.length`를 우선 사용한다.
  - `members`가 없는 과거 데이터는 `attendance`만 표시 가능하다고 간주한다.
  - 이 경우 출석률은 계산하지 않고 출석 인원 중심으로만 보여 준다.

## 화면 구조

### 1. 상단 요약
- 최근 주일 출석
- 이번 달 평균 출석
- 이번 달 집계 주차 수
- 가능하면 총원 기반 출석률

### 2. 최근 주간 목록
- 최근 N주를 카드 목록으로 표시한다.
- 기본은 최근 8주
- 카드 항목:
  - 보고일
  - 출석 인원
  - 총원 또는 출석률
  - 간단 상태 배지 (`최근`, `이번 달` 등)

### 3. 월별 요약
- 최근 12개월 기준
- 월별 평균 출석과 월별 최고/최저를 함께 보여 준다.
- 초기 구현은 표 또는 카드형 요약으로 간다.
- 차트 라이브러리는 도입하지 않는다.

## UI 원칙
- 현재 회의자료 사이트의 블루 톤과 카드 스타일을 그대로 따른다.
- 문서 목록보다 숫자 정보가 더 빨리 읽히도록 통계 카드를 우선 배치한다.
- 데스크탑에서는 `요약 → 주간 → 월별` 순으로 내려가고, 모바일에서는 세로 1열로 정리한다.
- 읽기 전용 화면이므로 편집 버튼, 토글, 저장 액션은 두지 않는다.

## 네비게이션 동작
- 사이드바에 `출결현황`을 추가한다.
- 클릭 시 `attendance.html`로 이동한다.
- `attendance.html`에도 기존과 같은 사이드바를 유지해 다른 메뉴로 다시 이동할 수 있게 한다.

## 동기화 및 권한
- 이 화면은 읽기 전용이다.
- 실제 수정은 계속 `ministry-report-v2`에서 한다.
- 회의자료 사이트는 Firebase 설정을 추가로 받아 Firestore read만 수행한다.
- 인증이 꼭 필요한 Firestore 규칙이면, 이 설계는 바로 동작하지 않는다.
- 그 경우 대체안은 `중고등부 전용 공개 집계본을 별도 경로에 미러링`하는 것이다.
- 이번 구현은 우선 `현재 규칙이 읽기를 허용하거나 익명 읽기 구성이 가능하다`는 전제 위에 진행한다.

## 구현 범위
- [index.html](../../../index.html) 사이드바에 `출결현황` 메뉴 추가
- [attendance.html](../../../attendance.html) 신규 생성
- Firestore 읽기용 스크립트 추가
- 중고등부 주간/월간 집계 함수 구현
- 빈 데이터, 로딩, 읽기 실패 상태 UI 구현

## 구현 제외
- 출결 직접 수정 기능
- 출석 카드 드래그/체크 UI
- 전체 부서 통합 대시보드
- 차트 라이브러리 도입
- `ministry-report-v2` 내부 코드 구조 변경

## 에러 처리
- Firestore 읽기 실패 시:
  - 출결 카드 대신 실패 안내 문구 표시
  - 수정은 `ministry-report-v2`에서 한다는 안내 제공
- 보고서가 0건이면:
  - 빈 상태 카드 표시
- 중고등부 필드가 일부 없는 보고서는:
  - 해당 항목을 건너뛰거나 제한 정보만 사용

## 검증 기준
- 회의자료 사이트에서 `출결현황` 메뉴가 보인다.
- `attendance.html`에서 최근 주간 목록과 월별 요약이 모두 보인다.
- 표시 데이터는 `reports` 컬렉션의 `middleHigh` 값과 일치한다.
- 빈 데이터와 실패 상태가 깨지지 않는다.
- 다른 회의자료 메뉴 구조는 유지된다.
