# 학생 명단 전용 페이지 (roster.html) 설계

## 배경

`attendance.html`에 임시로 넣었던 학생 명단 섹션은 이름만 관리하는 간단한 형태였다. 이번 작업은 이를 독립 페이지로 분리하고, 전화번호/생일/학교/주소 등 상세 정보를 관리할 수 있도록 리뉴얼한다.

## 페이지 구성

- 새 파일 `roster.html` 생성. `attendance.html`과 동일한 톱바(로고 + 뒤로가기) 톤을 따르되, 상단 전역 네비게이션에는 링크를 추가하지 않는다 — 자주 보는 페이지가 아니므로 `index.html`의 카드에서만 진입한다.
- `index.html`의 "출결현황" 섹션에 있는 "학생 명단" 카드의 링크를 `attendance.html#members-section` → `roster.html`로 변경한다.
- `attendance.html`에 임시로 추가했던 `#members-section` 섹션, `members-sync.js` 스크립트 로드, 관련 CSS를 제거한다.

## 데이터 모델

RTDB 경로는 기존과 동일하게 유지하되 필드를 확장한다.

```
members/{학년}/{pushId}: {
  name: string,       // 필수
  phone: string,       // 선택
  birthday: string,     // 선택, YYYY-MM-DD
  school: string,      // 선택
  address: string       // 선택
}
```

학년 키: `중1`, `중2`, `중3`, `고1`, `고2`, `고3` (기존과 동일).

기존에 이름만 들어있던 데이터는 마이그레이션 없이 그대로 사용한다 — 나머지 필드는 `undefined`로 취급하고, 화면에서는 빈 값으로 렌더링한다. 사용자가 칩을 클릭해 수정 모달을 열고 값을 채우면 자연스럽게 채워진다.

## UI

### 레이아웃
`attendance.html`에 있던 것과 동일하게 2열 그리드(중학교 열 / 고등학교 열), 각 열 안에 학년별 블록(중1~중3, 고1~고3).

### 칩(카드)
- 기본 상태: 이름만 표시하는 작은 칩.
- 클릭 시: 칩이 펼쳐지며(또는 별도 상세 패널) 전화번호/생일/학교/주소를 표시. 다시 클릭하면 접힘.
- 상세 펼침 안에 "수정" 버튼을 두어 같은 학생의 입력 모달을 채운 값으로 연다.

### 입력/수정 모달
- 학년 선택 드롭다운 + 이름/전화번호/생일/학교/주소 입력 필드를 한 번에 보여주는 모달 하나로 추가와 수정을 겸한다.
- "+" 버튼(학년 블록 헤더에 위치, 기존 UI 패턴 유지)으로 신규 추가 모달을 연다 — 이때는 해당 학년이 미리 선택된 상태.
- 칩 상세의 "수정" 버튼으로 열면 기존 값이 채워진 상태로 연다.
- 저장 시 RTDB에 `set()`으로 반영 (신규는 `push()` 후 `set()`, 수정은 기존 키에 `update()`).
- 학년을 바꿔서 저장하면 기존 학년 경로에서 삭제하고 새 학년 경로에 추가한다.

### 권한
- 추가: 자유 (PIN 불필요)
- 수정: 자유 (PIN 불필요)
- 삭제: 기존 PIN 해시(`b6c7470ca0e1b2126ca179990624575fd44cc6506bfc544022970fe83b74ebdf`, PIN 006291)로 보호. 칩 상세 안 "삭제" 버튼 클릭 시 PIN 프롬프트.
- 페이지 열람 자체는 보호 없음 — 팀 내부에서만 쓰는 도구이므로.

## 파일 변경 목록

- **생성**: `roster.html` — 페이지 골격 + 학년 그리드 + 모달 마크업 + CSS
- **생성**: `roster-sync.js` — RTDB CRUD 로직 (기존 `members-sync.js`를 대체)
- **삭제**: `members-sync.js` (roster-sync.js로 대체되어 더 이상 불필요)
- **수정**: `attendance.html` — `#members-section` 섹션, `members-sync.js`/`sync-config.js`/`firebase-database-compat.js` 로드, 관련 CSS 블록 제거
- **수정**: `index.html` — "학생 명단" 카드의 `href`를 `roster.html`로 변경
- **수정**: `firebase-database.rules.json` — 기존 `members` 경로 규칙 그대로 유지 (필드 확장은 스키마리스 RTDB라 규칙 변경 불필요)

## 테스트 방법

브라우저에서 로컬 서버로 `roster.html`을 열어:
1. "+"로 학생 추가 → 학년 블록에 칩으로 나타나는지 확인
2. 칩 클릭 → 상세 필드 펼침 확인
3. 수정 버튼 → 모달에 기존 값 채워진 채로 열리는지, 저장 후 반영되는지 확인
4. 삭제 버튼 → PIN 오류 시 삭제 안 됨, 올바른 PIN 시 삭제되는지 확인
5. 기존에 이름만 있던 학생 칩이 정상적으로 보이는지(빈 필드 처리) 확인
